### What I do

I build **C++ microservices, ESP32 firmware, and Angular dashboards** that make a home run itself — no cloud, no broker, no telemetry leaving the house. Everything talks over MQTT and Home Assistant, runs native on a single low-power box, and stays alive whether or not the internet does.

My focus is **local-first automation for things that actually matter**: medical data (CPAP therapy), power resilience (UPS/grid), security cameras, and the dozens of small bridges that get stubborn BLE/WiFi devices to behave.

- 🔧 **C++17** (Drogon, libcurl, sdbus) — fast, tiny-footprint services (<20 MB total stack)
- 📡 **ESP32 / ESP-IDF** — BLE & WiFi-SD bridges, firmware for devices that ship no API
- 🖥️ **Angular** dashboards + **PostgreSQL / MQTT** plumbing
- 🤖 **Local ML & LLMs** — Ollama, embeddings, on-prem inference (zero data leaves the LAN)
